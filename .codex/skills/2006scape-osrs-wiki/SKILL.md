# 2006Scape OSRS Wiki

Use the Old School RuneScape Wiki for quick external research when local docs, cache data, or live observation do not answer a question fast enough. Search exact modern OSRS names first, then broaden if needed.

## When To Use

- You need a fast clue for where an item, NPC, object, or activity is usually found.
- You need the modern OSRS name for something before implementing or playing.
- You want a reference for requirements, unlocks, or expected mechanics before trusting local assumptions.

## Guardrails

- The wiki describes modern OSRS, not this repo's 2006Scape ruleset.
- Use it as a hint, then verify against local cache, server data, scripts, or live state.
- Content may be missing here, renamed here, or behave differently here.
- If the wiki and the server disagree, trust the server and local evidence.

## Search Hints

- Prefer the wiki search URL or page search with exact terms first.
- Retry with aliases, partial names, or the modern OSRS term if the local name is unclear.
